# مدار · اللوحات التنفيذية

لوحة القيادة التنفيذية و22 لوحة موديولات، داخل نظام **مدار** وبتصميمه، تحت عنصر جديد في القائمة اسمه **«اللوحات التنفيذية»**.
البيانات كلها تجريبية.

- **التصميم:** واجهة مدار الجديدة (madar-new-design)، أي الشريط الجانبي والقائمة المنبثقة والبحث السريع (Ctrl K) والإشعارات وقائمة المستخدم. البطاقات بإطار زجاجي مزدوج، والعناوين بخط Cairo والنصوص بخط Tajawal.
- **الألوان:** كل لون في اللوحات مربوط بألوان مدار، فيعمل **الوضع الداكن** و**لوحات الألوان الثماني** (ذهب الرمال، أخضر الحرم، سماء الليل…) من قائمة المستخدم.
- **اللغة:** العربية افتراضيًا. زر English في الرأس يحوّل الواجهة إلى الإنجليزية مباشرة، دون إعادة تحميل.
- **صلاحيات العرض:** من بطاقة المستخدم في الرأس تختار نطاق الإدارة (مكة والمدينة، أو مكة، أو المدينة) وطريقة الدخول (مدير الإدارة، أو منظم لجنسية واحدة).

## التشغيل

افتح `index.html` في المتصفح. يمكنك أيضًا تشغيل خادم محلي:

```bash
python -m http.server 8080
# ثم افتح http://localhost:8080
```

يفتح الموقع على `#/ex`، وهي لوحة القيادة التنفيذية. يعمل كما هو على GitHub Pages.

> صفحات مدار الأخرى في القائمة (الرئيسية، الفنادق، الحجاج…) تُقرأ من موقع التصميم المباشر
> `https://gama-ksa.github.io/madar-new-design/`، وتحتاج اتصالًا بالإنترنت. العنوان معرّف في `index.html` باسم `window.MADAR_REMOTE`.
> اللوحات التنفيذية نفسها محلية بالكامل.

## البنية

```
index.html              غلاف مدار: يحمّل الشريط والقائمة واللوحات التنفيذية
app/                    غلاف مدار (من madar-new-design) مع تعديلات قليلة موسومة بـ MAD-EXEC:
  menu.js                 مجموعة «اللوحات التنفيذية» بعناصرها الـ23
  app.js                  المسار #/ex، والعربية افتراضيًا، وتحميل صفحات مدار الأخرى من MADAR_REMOTE
assets/                 خطوط مدار (Cairo وTajawal) وشعاره
exec/
  exec-shell.js           تركيب اللوحات في مدار: الرأس، تبويبات الأقسام، المسارات، الإنجليزية، صلاحيات العرض
  exec.css                رموز ألوان مدار (فاتح وداكن ولكل لوحة ألوان) وطبقة التصميم
  dashboards.css          تنسيقات اللوحات، مولّدة من المصدر (لا تُعدَّل يدويًا)
  js/*.js                 منطق اللوحات وبياناتها التجريبية، مولّدة من المصدر
  markup.js, i18n-data.js هيكل اللوحة التنفيذية والقاموس الإنجليزي، مولّدان
  flags/                  أعلام الدول
tools/port-dashboards.py  أداة التحويل من النموذج الأصلي إلى تصميم مدار
```

## إعادة التوليد عند تحديث النموذج الأصلي

الملفات المولّدة (`exec/dashboards.css` و`exec/js/` و`exec/markup.js` و`exec/i18n-data.js`) تُبنى من نسخة محفوظة من النموذج الأصلي.
تحتاج الأداة إلى `index.html` وملفات `*.js` و`*.css` ومجلد `flags/`.

```bash
python3 tools/port-dashboards.py <مجلد النموذج الأصلي> .
```

الأداة تفعل ما يلي:
- تحصر التنسيقات تحت `.ex-root` حتى لا تتداخل مع غلاف مدار.
- تحوّل كل لون إلى رمز من ألوان مدار حسب دوره: نص، أو تعبئة، أو حدّ.
- تنقل الخطوط إلى Tajawal، وCairo للعناوين والأرقام.
- تستبدل الاسم القديم بـ«مدار».

أما التعديلات اليدوية على الشكل فمكانها `exec/exec.css`.

## ملاحظات

- الأرقام والرحلات والمراكز والأسماء كلها تجريبية، وتعريفات المؤشرات تحتاج مطابقتها مع النظام الفعلي قبل ربط البيانات.
- الترجمة الإنجليزية تأتي من قاموس النموذج الأصلي. تغطيته جيدة في اللوحة التنفيذية وجزئية في بعض لوحات الموديولات، فتبقى فيها نصوص عربية.
